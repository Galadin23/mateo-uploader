Privacy policy

Effective 11 November 2026. This policy covers Mateo Uploader, a private tool used only by the Mateo YouTube channel.

What it accesses

With the channel owner's permission (Google sign-in), the tool uses the YouTube Data API to upload the channel's own videos, read the channel's recent uploads and their release times, and change the release time of videos that are scheduled but not yet public. It does not read comments, messages, analytics or any other account data.

What it stores

One Google sign-in token, kept on the channel's own editing computer so uploads can run without signing in each time. Nothing is stored anywhere else.

Sharing

No data is sold, shared or sent to anyone other than Google/YouTube. This website uses no cookies and no analytics.

Mateo Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The channel owner can remove the tool's access at any time at myaccount.google.com/permissions.

Contact

Through an issue on this site's GitHub page.
